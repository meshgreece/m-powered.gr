# Κατανομή preset ανά περιοχή

Στον χάρτη του m-powered.gr, επίλεξε μια περιφερειακή ενότητα για να δεις τους καταγεγραμμένους κόμβους Meshtastic και τις ενδείξεις preset. Για το κοινοτικό δίκτυο εφάρμοσε το [προφίλ ρυθμίσεων NarrowSlow](./configuration-generator?preset=NarrowSlow), ανεξάρτητα από το χρώμα της περιοχής σου.
