# Κατανομή preset ανά περιοχή

Επίλεξε μια περιφερειακή ενότητα για να δεις τους καταγεγραμμένους κόμβους και τα presets τους. Δες [ποιο preset να επιλέξεις](./network-settings#ποιο-preset-να-επιλέξεις) για το τοπικό mesh.

Το `NarrowSlow` χρησιμοποιείται κυρίως στην Αττική και σε γύρω περιοχές. Για να συνδεθείς στο NarrowSlow mesh, επίλεξε το [προφίλ NarrowSlow](./configuration-generator?preset=NarrowSlow), ακόμη κι αν ο χάρτης δεν δείχνει τοπικούς κόμβους. Σε άλλες περιοχές, ακολούθησε το preset του τοπικού mesh.

Αν δεν βλέπεις κόμβους, δεν γνωρίζεις κοντινό mesh και δεν σκοπεύεις να συνδεθείς σε NarrowSlow mesh, ξεκίνα με το [προφίλ LongFast](./configuration-generator?preset=LongFast). Είναι η προεπιλογή του Meshtastic και βοηθά νέους χρήστες να βρουν ο ένας τον άλλον.
